# 🐱 Whisker Fit

A Phaser 4 puzzle game.

## How to Play

```
npm install
npm run dev
```

## Tech Stack

- **Engine**: Phaser 4
- **Build Tool**: Vite
- **Language**: TypeScript

## Deploy

Push to `main` branch → GitHub Actions auto-builds and deploys to GitHub Pages.

🔗 Live: https://sid33xd.github.io/Polyominoes
